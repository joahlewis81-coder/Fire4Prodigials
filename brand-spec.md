# Fire4Prodigals brand spec

- Logo: `public/brand/logo.png` (always use the real logo; never redraw it)
- Colors (tokens in `app/globals.css`):
  - Ink `#0d0b0a` (main background), Ash `#171310`, Char `#241d18`
  - Ember orange `#f26a1b` (buttons, highlights), Ember soft `#ff9a4d`
  - Flame red `#c8281e` (sparing accents)
  - Bone `#f3ede4` (text on dark), Paper `#faf6f0` (light sections)
- Fonts: Instrument Serif (headlines, scripture in italic), Manrope (everything else)
- Photos: `public/images/photos/`, flyers: `public/images/flyers/` (regenerate with `npm run images`)
- Voice: warm, direct, hopeful. "Come as you are." Scripture: Matthew 11:28, Psalm 40:2, John 8:36.
- Motion: slow ease-out (cubic-bezier(0.16, 1, 0.3, 1)), rise-and-fade reveals, all disabled for reduced-motion users.
